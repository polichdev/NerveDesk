Швидке підключення через QR-код
Генерація QR...
Як підключити телефон:
  1. Підключіть телефон до тієї ж Wi-Fi мережі, що й ПК.
  2. Відскануйте QR-код камерою або введіть адресу в браузері.
  3. Введіть 6-значний PIN-код для безпечного входу.
  4. Керуйте комп'ютером у режимі «Екран» або «Тачпад».

Загальні налаштування
Налаштування параметрів програми, оформлення, мови та мережевих зв'язків.
Тема оформлення
Оберіть кольорову гаму інтерфейсу програми: світлу, темну або автоматичну системну.
Мова інтерфейсу
Оберіть бажану мову для всіх екранів та сповіщень програми.
Запуск разом із системою
Автоматично запускати NerveDesk у фоновому режимі під час старту Windows.
Прив'язка до локальної підмережі
Приймати підключення лише від пристроїв, що розташовані в тій самій підмережі IPv4.
